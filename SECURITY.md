<h1>Security</h1>

<p>MoneyBug holds people's client details, invoices and time, so security problems are taken seriously. If you think you've found one, thank you for reporting it privately.</p>

<h2>Reporting a vulnerability</h2>

<p><strong>Please don't report security problems in public issues or Discussions.</strong> Instead, use <a href="https://github.com/oddforms-design/MoneyBug/security/advisories/new">Report a vulnerability</a> on this repository's Security tab, or email <a href="mailto:support@oddforms.com?subject=Security">support@oddforms.com</a> with "Security" in the subject.</p>

<p>Helpful things to include:</p>
<ul>
  <li>What the problem is, and what someone could do with it</li>
  <li>The steps to reproduce it</li>
  <li>Your macOS version and MoneyBug version</li>
</ul>

<p>Please don't include anyone's real client data, and don't access data that isn't yours.</p>

<h2>What's covered</h2>

<p>The MoneyBug app for Mac, including its local library, backups and their encryption, Sync with iCloud, and the app lock.</p>

<h2>What to expect</h2>

<ul>
  <li>I'll confirm I've received your report, usually within a few days. MoneyBug is made by one person, so please allow some time.</li>
  <li>I'll let you know what I find, and when a fix ships in an update.</li>
  <li>Please give me a reasonable chance to release a fix before sharing details publicly. I'm glad to credit you in the release notes if you'd like.</li>
</ul>

<p>There's no bug bounty.</p>
